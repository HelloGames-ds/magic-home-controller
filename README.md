A native Windows controller for **Magic Home / Flux LED** RGB LED strips and bulbs, built with C++17, Qt 6 Widgets, and Qt Network (TCP/UDP).

---

## Features

- Wi-Fi discovery (UDP broadcast) and control over TCP (Magic Home protocol, port 5577)
- Manual IP entry with automatic reconnection
- HSV color wheel, brightness control, and smooth color transitions
- 11 effects: built-in controller patterns run on the device, the rest are generated by software
- Editable palettes with two to four colors
- Ambilight screen capture with monitor, region, and capture-backend selection
- Screen capture backends: **WGC** (Windows.Graphics.Capture), **DXGI** desktop duplication, and legacy **GDI** with automatic fallback
- 13 capture regions, including grids and a custom rectangle
- Average, brightest, and most saturated sample-combination modes
- System tray integration and a quick-settings popup
- Persistent settings and optional Windows startup
- Diagnostic log window and log file

---

## Requirements

- Windows 11 x64 (WGC backend requires Windows 11 24H2 or newer; DXGI and GDI work on older builds)
- Wi-Fi network connection (wired is also fine for the controller)
- A Magic Home / Flux LED controller reachable over the local network (TCP port 5577)

> **Ambilight and full screen:** for capture to work, games should run in **windowed or borderless** mode. Exclusive full screen is not exposed to screen capture APIs.

## Installation

### Option 1: Installer — recommended

1. Open the repository's **Releases** page.
2. Download `Magic-Home-Controller-Setup-1.0-x64.exe` from the latest release.
3. Run the installer and accept the Windows UAC prompt.
4. Launch **Magic Home Controller** from the Start menu or the optional desktop shortcut.

The default installation directory is:

```text
C:\Program Files\Magic Home Controller
```

The installer is approximately 38 MB and includes the required Qt libraries and MSVC runtime. Qt does not need to be installed separately.

The installation wizard can optionally create a desktop shortcut and enable startup with Windows.

### Option 2: Portable package

Download the portable Windows artifact, extract the entire directory, and run `Magic-Home-Controller.exe`.

Do not move only the executable out of the portable directory: the adjacent Qt DLLs and plugin folders are required.

---

## First connection

Make sure the controller and your computer are on the same network.

You can enter the controller IP manually on the **Settings** tab, or find it automatically:

1. Open the **Settings** tab.
2. Click **Find Magic Home devices**.
3. Select the controller from the list and click **Use selected** (the IP will be filled in).

The application automatically attempts to reconnect after temporary connection loss and restores the last color/pattern after reconnecting.

## Building from source

Required tools:

- Visual Studio with the Desktop development with C++ workload
- CMake
- Ninja
- Qt 6.8 with the Widgets and Network modules
- Inno Setup 6 for creating the installer
- C++/WinRT headers (bundled in `vendor/winrt`)

The project targets MSVC x64 with C++17. WGC support is built for MSVC only (coroutines, C++/WinRT projection).

Build the portable Release package:

```bat
build-release.cmd
```

The result is written to `dist-cpp\`.

Build the Windows installer:

```bat
build-installer.cmd
```

The installer is written to:

```text
installer-output\Magic-Home-Controller-Setup-1.0-x64.exe
```

## Configuration and logs

User settings and logs are stored in:

```text
%APPDATA%\Magic Home Controller
```

Main files:

- `config.ini` — application settings
- `last.log` — diagnostic log

These files belong to the current user and are not stored in the installation directory.

## Project structure

- `src/MainWindow.*` — main window and application coordination
- `src/WifiWorker.*` — TCP connection, queue, pacing, and reconnect logic
- `src/DeviceScanner.*` — UDP device discovery
- `src/ColorWheel.*` — HSV color wheel
- `src/ColorSmoother.*` — HSV transition smoothing
- `src/EffectEngine.*` — software effects
- `src/protocol.h` — Magic Home wire protocol (packets and checksum)
- `src/AmbiLight.*` — screen capture and color processing
- `src/ScreenBackend.h` — capture backend interface
- `src/DxgiCapture.*` — DXGI desktop duplication backend
- `src/WgcCapture.*` — Windows.Graphics.Capture (WGC) backend
- `src/AmbiEditor.*` — Ambilight editor
- `src/TrayPopup.*` — quick-settings popup
- `src/SettingsStore.*` — persistent settings and Windows startup
- `src/AppLog.*`, `src/LogWindow.*` — logging
- `installer.iss` — Inno Setup configuration
- `.github/workflows/windows-build.yml` — GitHub Actions Windows build
