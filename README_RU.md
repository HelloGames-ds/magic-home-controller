Нативный контроллер RGB-ленты и ламп **Magic Home / Flux LED** для Windows, написанный на C++17 с использованием Qt 6 Widgets и Qt Network (TCP/UDP).

---

## Возможности

- Поиск устройств по Wi-Fi (UDP-broadcast) и управление по TCP (протокол Magic Home, порт 5577)
- Ручной ввод IP-адреса и автоматическое переподключение
- HSV-колесо, управление яркостью и плавные переходы цветов
- 11 эффектов: встроенные паттерны выполняются на контроллере, остальные — программно
- Редактируемая палитра из двух–четырёх цветов
- Ambilight с выбором монитора, области экрана и бэкенда захвата
- Бэкенды захвата экрана: **WGC** (Windows.Graphics.Capture), **DXGI** desktop duplication и легаси-**GDI** с автоматическим переключением
- 13 областей захвата, включая сетки и пользовательский прямоугольник
- Объединение семплов по среднему, яркости или насыщенности
- Системный трей и окно быстрых настроек
- Сохранение конфигурации и необязательный автозапуск Windows
- Диагностический журнал

---

## Требования

- Windows 11 x64 (бэкенд WGC требует Windows 11 24H2 или новее; DXGI и GDI работают на более старых сборках)
- Подключение к сети (контроллеру достаточно проводной сети)
- Контроллер Magic Home / Flux LED в локальной сети (TCP-порт 5577)

> **Ambilight и полный экран:** для корректного захвата игры должны работать в **оконном или borderless** режиме. Эксклюзивный fullscreen недоступен для API захвата экрана.

## Установка

### Вариант 1: Установщик — рекомендуется

1. Откройте страницу **Releases** репозитория.
2. Скачайте `Magic-Home-Controller-Setup-1.0-x64.exe` из последнего релиза.
3. Запустите установщик и подтвердите запрос Windows UAC.
4. Запустите **Magic Home Controller** из меню «Пуск» или с созданного ярлыка.

По умолчанию программа устанавливается в:

```text
C:\Program Files\Magic Home Controller
```

Размер установщика — около 38 МБ. В него уже входят необходимые библиотеки Qt и MSVC Runtime, поэтому отдельно устанавливать Qt не требуется.

Установщик может создать ярлык на рабочем столе и включить запуск вместе с Windows.

### Вариант 2: Переносимая сборка

Скачайте переносимую Windows-сборку, распакуйте всю папку и запустите `Magic-Home-Controller.exe`.

Не переносите только EXE отдельно: программе необходимы расположенные рядом библиотеки Qt и каталоги плагинов.

## Первое подключение

Убедитесь, что контроллер и компьютер находятся в одной сети.

IP-адрес контроллера можно ввести вручную на вкладке **Настройки** или найти автоматически:

1. Откройте вкладку **Настройки**.
2. Нажмите **Найти Magic Home в сети**.
3. Выберите контроллер из списка и нажмите **Использовать выбранное** (IP подставится автоматически).

После временного разрыва приложение автоматически переподключается и восстанавливает последний цвет/паттерн.

## Сборка из исходного кода

Необходимы:

- Visual Studio с workload Desktop development with C++
- CMake
- Ninja
- Qt 6.8 с модулями Widgets и Network
- Inno Setup 6 для создания установщика
- Заголовки C++/WinRT (поставляются в `vendor/winrt`)

Проект ориентирован на MSVC x64 с C++17. Поддержка WGC собирается только под MSVC (корутины, проекция C++/WinRT).

Сборка переносимой Release-версии:

```bat
build-release.cmd
```

Результат создаётся в `dist-cpp\`.

Сборка установщика:

```bat
build-installer.cmd
```

Готовый установщик:

```text
installer-output\Magic-Home-Controller-Setup-1.0-x64.exe
```

## Настройки и журнал

Пользовательские настройки и журнал хранятся в:

```text
%APPDATA%\Magic Home Controller
```

Основные файлы:

- `config.ini` — настройки приложения
- `last.log` — диагностический журнал

Эти файлы принадлежат текущему пользователю и не хранятся в каталоге установки.

## Структура проекта

- `src/MainWindow.*` — главное окно и координация приложения
- `src/WifiWorker.*` — TCP-подключение, очередь, интервалы и reconnect
- `src/DeviceScanner.*` — UDP-поиск устройств
- `src/ColorWheel.*` — HSV-колесо
- `src/ColorSmoother.*` — сглаживание переходов в HSV
- `src/EffectEngine.*` — программные эффекты
- `src/protocol.h` — сетевой протокол Magic Home (пакеты и контрольная сумма)
- `src/AmbiLight.*` — захват экрана и обработка цвета
- `src/ScreenBackend.h` — интерфейс бэкенда захвата
- `src/DxgiCapture.*` — бэкенд DXGI desktop duplication
- `src/WgcCapture.*` — бэкенд Windows.Graphics.Capture (WGC)
- `src/AmbiEditor.*` — редактор Ambilight
- `src/TrayPopup.*` — быстрые настройки из трея
- `src/SettingsStore.*` — сохранение настроек и автозапуск
- `src/AppLog.*`, `src/LogWindow.*` — журналирование
- `installer.iss` — конфигурация Inno Setup
- `.github/workflows/windows-build.yml` — Windows-сборка в GitHub Actions
